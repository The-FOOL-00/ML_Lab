\textbf{5} \textbf{Data Preprocessing}

\textbf{5.1} \textbf{Missing Value Handling:}

Missing values in numerical attributes were replaced using the median
value, while missing values in categorical attributes were replaced
using the most frequent category using the SimpleImputer class.

\textbf{5.2} \textbf{Encoding:}

Categorical variables such as Gender, Married, Education, Self\_Employed
and Prop-erty\_Area were converted into numerical format using One-Hot
Encoding to make them suitable for machine learning algorithms.

\textbf{5.3} \textbf{Feature Scaling:}

Numerical attributes were standardized using StandardScaler so that all
features have zero mean and unit variance. This improves model stability
during training.
\end{quote}

\textbf{6} \textbf{Machine Learning Algorithm}\\
\textbf{6.1} \textbf{Working Principle}\\
Linear Regression is a supervised learning algorithm used to predict
continuous numerical values. It models the relationship between the
dependent variable and one or more independent variables by fitting the
best straight line that minimizes prediction error.

\textbf{6.2} \textbf{Mathematical Formulation}\\
The prediction equation is
\end{quote}

\[y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + \cdots + \beta_n x_n\]

\begin{quote}
where
\end{quote}

\begin{quote}
• $y$ is the predicted output,\\
• $\beta_0$ is the intercept,\\
• $\beta_i$ are regression coefficients,\\
• $x_i$ are input features.

The model minimizes the Mean Squared Error (MSE)
\end{quote}

\[MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2\]
